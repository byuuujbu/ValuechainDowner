# OVSA Decisions v0.2

작성일: 2026-05-31

## 확정 결정

1. OVSA v0.1의 최우선 정체성은 객관 지표 기반 후보 검토와 감정매매 방지 도구다.
2. `후보 가능`은 매수 추천이 아니라 추가 검토 자격 통과를 의미한다.
3. v0.1 상태값은 `후보 가능`, `관망`, `제외` 세 가지로 제한한다.
4. `Strategic Fit Score`는 종합 투자점수와 후보 판정에 반영하지 않는다.
5. 우주 산업 Value-chain 맵은 검수된 시드 데이터 기반 맵으로 구현한다.
6. AI는 Value-chain 초안과 기업 배치 후보를 제안할 수 있지만, 사람 검수 없이 화면에 반영하지 않는다.
7. v0.1은 샘플 데이터와 Mock/Sample Provider를 우선한다.
8. 실제 한국/미국 주가·재무 API 연동은 Provider Interface를 유지한 뒤 후속 단계에서 어댑터로 확장한다.
9. 비교집단은 단순하고 재현 가능한 기준으로 시작하되, 정교화 가능한 설정과 로그 구조를 둔다.
10. ETF는 DB, 관심종목, 벤치마크, 비교 대상으로 포함하지만 개별주와 같은 종합 투자점수 체계에는 넣지 않는다.
11. Rule Engine은 후보 판정 차단과 최소 보유 알림까지 구현한다.
12. 투자일지는 감정매매 방지 장치로 구현하고, 매도 후 회고를 v0.1에 포함한다.
13. 백테스트는 샘플 기반 구조 검증 도구로 두며 실제 성과 보장 도구로 표현하지 않는다.
14. 운영 주기는 `3일마다 스크리닝`, `2주마다 리밸런싱 검토`로 수정한다.
15. Discord는 마지막 Phase로 유지하고, Web App과 Backend Core가 안정된 뒤 붙인다.
16. Phase 1은 프로젝트 골격만 만든다.
17. 개발은 Phase별 승인 게이트 방식으로 진행한다.
18. v0.1 사용자 범위는 개인/가족/지인용으로 고정하고 SaaS 기능은 제외한다.
19. 금융 규제와 투자자문 오해 방지 원칙을 최상위 원칙으로 강화한다.
20. 화면 우선순위는 대시보드 중심이며, 산업맵은 주요 탭으로 둔다.
21. 산업맵 구조는 우주 산업만 상세 구현하되 AI, 반도체, 의학·바이오, 로봇 등 다른 산업 확장을 고려해 일반화한다.
